Latest release

A coding agent that asks first.

agenticc works in your own repositories from a terminal chat, a one-shot CLI or a macOS app. It asks before it writes or runs anything, runs commands in an operating-system sandbox, and records every step so an interrupted turn can be resumed.

$curl -fsSL https://github.com/nakiner/agenticc-releases/releases/latest/download/install.sh | sh

macOS and Linux. Checks the SHA-256, installs to ~/.local/bin, never uses sudo.

Download for Mac .dmg Release notes

Built to be trusted with your code

One Go core drives every surface, so the same rules hold whether you chat in the terminal, script it, or use the desktop app.

Asks before it acts

Every write and every command waits for your answer, and you see exactly what will run. Allow once, or for the session.

Sandboxed commands

Commands run in the operating system's sandbox, with your secrets and other projects closed off. A command you approve to run outside it is clearly marked.

A journal of every step

Each turn is recorded in a crash-safe journal, so an interrupted turn can be resumed and everything the agent did can be audited.

Terminal, CLI and Mac app

A terminal chat, a one-shot command for scripts, a native macOS app, a local web UI, and the Agent Client Protocol for editors.

Careful with your budget

Small tool output and steady prompt caching keep the cost down: seven repair tasks cost $2.98 on Opus 5.5 and $0.96 on GPT 6.1 Sol (median of three runs).

Updates itself, safely

agenticc update and the app check every update's checksum and signature, and keep the previous version to roll back to.

Everything included

No cloud service in between: agenticc runs on your machine and talks to your provider directly.

The macOS app

  • Workspaces, scratch chats and split view, on Liquid Glass
  • Any chat in a window of its own; settings in another
  • An approval panel that floats above other apps
  • Approve a short command right from its notification
  • A menu bar icon that keeps turns running with the window closed
  • Changes panel with per-hunk revert, managed git worktrees, rewind
  • ⌘K command palette and a global ⌘⇧Space shortcut

Terminal and automation

  • A terminal chat with slash commands, queued messages and rewind
  • agenticc run for scripts, with --json or a live event stream
  • A local web UI with agenticc serve
  • Editors over the Agent Client Protocol
  • agenticc as an MCP server for other agents
  • A GitHub Action for reviews and tasks in CI

Make it yours

  • Skills, lifecycle hooks and custom agents
  • MCP servers: tools, resources, prompts and OAuth login
  • WebAssembly plugins limited to the capabilities they declare
  • Sub-agents, and a pair mode with a lead, a sidekick and a reviewer
  • Schedules for recurring tasks

Stay in control

  • Per-turn caps on cost, tokens, requests and time
  • Fallback models when a provider fails or a limit runs out
  • Your project's tests and linters run after the last edit, with a verification line on every answer
  • Undo, rewind and rollback from an append-only journal
  • An action whose outcome is unknown is never run twice

Install

Signed with a Developer ID and notarized by Apple on macOS. Every file is listed with its SHA-256 in the release.

Get started

  1. Run the install command above, or open the .dmg and drag agenticc to Applications.
  2. Run agenticc in a project folder and pick a provider.
  3. Later releases: agenticc update, or let the app update itself.

Another install folder: … | sh -s -- --prefix /opt/agenticc
